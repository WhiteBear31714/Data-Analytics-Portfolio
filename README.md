# 📊 Data Analytics Portfolio

ยินดีต้อนรับสู่คลังรวบรวมโปรเจกต์วิเคราะห์ข้อมูล (Data Analytics Portfolio) ของฉัน คลังนี้ถูกจัดทำขึ้นเพื่อจัดเก็บ ชิ้นงาน ระบบแดชบอร์ดอัจฉริยะ และโปรเจกต์ฝึกฝนทักษะการบริหารจัดการข้อมูล ตั้งแต่ขั้นการเตรียมข้อมูล (Data Cleansing) ไปจนถึงการนำเสนอข้อมูลเชิงภาพ (Data Visualization) เพื่อค้นหา Insight ทางธุรกิจ

---

## 📂 โครงสร้างและรายละเอียดโปรเจกต์ภายในคลัง (Repository Structure)

ภายในคลังนี้แบ่งออกเป็น **5 โปรเจกต์ย่อย** ตามโฟลเดอร์หลักดังนี้:

### 1. 🧮 [00-Analytics-Skills-Practice](./00-Analytics-Skills-Practice)
*   **คำอธิบาย:** พื้นที่รวบรวมแบบฝึกหัด สคริปต์ และเทคนิคการคำนวณขั้นพื้นฐานจนถึงขั้นสูงสำหรับการเป็น Data Analyst
*   **ทักษะที่ใช้:** Data Cleansing, Fundamental SQL, Advanced Excel (VLOOKUP, Pivot Tables, Power Query)

### 2. 📈 [9Expert Sales Demo-Pivot](./9Expert Sales Demo-Pivot)
*   **คำอธิบาย:** โปรเจกต์วิเคราะห์ระบบยอดขายจำลองพรีเมียม นำข้อมูลมาสรุปผล สรุปมิติมุมมองทางธุรกิจผ่าน Pivot Table และการจัดกลุ่มข้อมูล
*   **ทักษะที่ใช้:** Data Transformation, Pivot Table Optimization, Business Metrics KPI

### 3. 📊 [BI](./BI)
*   **คำอธิบาย:** โปรเจกต์พัฒนาระบบรายงานเชิงลึกและแดชบอร์ดอัจฉริยะเพื่อการตัดสินใจเชิงกลยุทธ์ (Business Intelligence Dashboard)
*   **ทักษะที่ใช้:** Power BI / Tableau, DAX Formulas, Data Modeling, Dashboard Design

### 4. 🎬 [Netfix_report](./Netfix_report)
*   **คำอธิบาย:** รายงานการวิเคราะห์พฤติกรรมและแนวโน้มภาพยนตร์/ซีรีส์บนแพลตฟอร์ม Streaming สรุปประเภทคอนเทนต์ยอดนิยม ช่วงเวลาการปล่อยสื่อ และ Insights ของผู้ใช้งานทั่วโลก
*   **ทักษะที่ใช้:** Exploratory Data Analysis (EDA), Content Analysis, Data Storytelling

### 5. 📦 [amazon_sales_dataset](./amazon_sales_dataset)
*   **คำอธิบาย:** ระบบประมวลผลข้อมูลและรายงานสรุปยอดขายอัจฉริยะระดับสากล (Premium Edition) บนแพลตฟอร์ม Amazon วิเคราะห์ GMV, AOV แยกรอบเวลา ภูมิภาค และช่องทางการชำระเงิน พร้อมการเชื่อมต่อร่วมกับ Interactive Web UI
*   **ทักษะที่ใช้:** JavaScript (SheetJS, Chart.js), HTML/Tailwind CSS, Data Integration

---

## 🛠️ เทคโนโลยีและเครื่องมือหลักที่เลือกใช้ (Tech Stack)

*   **Data Manipulation & Analysis:** Microsoft Excel (Power Query, Pivot), SQL, Python (Pandas)
*   **Data Visualization & BI:** Power BI, Chart.js
*   **Front-End Web UI & Presentation:** HTML5, Tailwind CSS, Lucide Icons
*   **Version Control:** Git & GitHub
