# 📦 Amazon Sales Intelligence Dataset

ระบบประมวลผลและฐานข้อมูลรายงานยอดขายสินค้าบนแพลตฟอร์ม Amazon (Global Marketplace) สำหรับใช้วิเคราะห์พฤติกรรมผู้บริโภค เทรนด์สินค้า และประสิทธิภาพช่องทางการชำระเงินในภูมิภาคต่าง ๆ ทั่วโลก

## 📊 ภาพรวมข้อมูลภาพรวมเชิงสถิติ (Key Metrics)
จากการประมวลผลข้อมูลดิบจำนวน **50,000 รายการ** ได้ผลสรุปตัวเลขชี้วัดหลัก (KPIs) ของธุรกิจดังนี้:

*   **มูลค่ารวมยอดขายสุทธิ (Total GMV):** ฿32,866,573.74
*   **จำนวนคำสั่งซื้อทั้งหมด (Total Orders):** 50,000 ออเดอร์
*   **ปริมาณสินค้าที่จำหน่ายได้ (Total Units Sold):** 149,970 ชิ้น
*   **มูลค่าเฉลี่ยต่อตะกร้าสินค้า (Average Order Value - AOV):** ฿657.33

## 🔍 โครงสร้างไฟล์ข้อมูล (Data Schema)
ฐานข้อมูลในไฟล์ `Amazon_Sales_Dataset.csv.xlsx` แผ่นงาน `amazon_sales_dataset` ประกอบด้วยคอลัมน์สำคัญดังนี้:

| ชื่อคอลัมน์ (Column Name) | ประเภทข้อมูล (Data Type) | คําอธิบาย (Description) |
| :--- | :--- | :--- |
| `order_id` | Integer | รหัสอ้างอิงใบสั่งซื้อ (Unique Key) |
| `order_date` | Datetime | วันที่และเวลาที่เกิดรายการคำสั่งซื้อ |
| `product_id` | Integer | รหัสสินค้าประจำรายการ |
| `product_category` | String/Object | หมวดหมู่กลุ่มผลิตภัณฑ์หลัก (มี 6 กลุ่ม) |
| `price` | Float | ราคาขายตั้งต้นของสินค้า (ก่อนหักส่วนลด) |
| `discount_percent` | Integer | เปอร์เซ็นต์ส่วนลดที่มอบให้ลูกค้า (0% - 20%) |
| `discounted_price` | Float | ราคาขายจริงหลังจากหักส่วนลดแล้ว |
| `quantity_sold` | Integer | จำนวนชิ้นของสินค้าที่ถูกซื้อในบิลนั้น |
| `total_revenue` | Float | ยอดรวมรายรับสุทธิประจำบิล (`discounted_price` × `quantity_sold`) |
| `customer_region` | String/Object | ภูมิภาคที่อยู่ของลูกค้าที่สั่งซื้อ |
| `payment_method` | String/Object | ช่องทางการชำระเงินที่ลูกค้าเลือกใช้ |
| `rating` | Float | คะแนนรีวิวความพึงพอใจต่อสินค้า (1.0 - 5.0) |
| `review_count` | Integer | จำนวนผู้เข้ามาร่วมเขียนรีวิวสินค้า |
